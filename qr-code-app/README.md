# مولّد الباركود

تطبيق بسيط لإنشاء رموز الباركود (QR)، يعمل على آيفون وأندرويد وكموقع ويب، مبني بـ Expo (React Native).
الواجهة عربية بالكامل ومن اليمين لليسار، وتوليد الباركود يتم على الجهاز نفسه بدون إنترنت.

## المميزات

- **منيو:** ارفع صورة أو ملف PDF للمنيو، فيُرفع تلقائياً إلى Cloudinary ويتحول رابطه إلى باركود مباشرة.
- إنشاء باركود لعشرة أنواع أخرى:
  رابط، نص، جهة اتصال، واي فاي، اتصال هاتفي، رسالة نصية، بريد إلكتروني، موقع جغرافي، حدث تقويم، واتساب.
- عرض الباركود بحجم كبير، مع:
  - **حفظ الصورة** في معرض الصور بجودة عالية.
  - **مشاركة** الصورة عبر قائمة المشاركة في الجهاز.
  - **تغيير اللون** من ثمانية ألوان جاهزة.
  - **إضافة شعار** في المنتصف من معرض الصور (اختياري).

## التجربة على الجوال عبر Expo Go (رابط دائم)

التطبيق يُنشر تلقائياً عبر **EAS Update** مع كل تعديل على المجلد، بواسطة الملف
`.github/workflows/qr-code-app-eas-update.yml` في جذر المستودع.

الإعداد مرة واحدة فقط:
1. أنشئ حساباً مجانياً في expo.dev.
2. من إعدادات الحساب ← **Access tokens** أنشئ رمزاً جديداً وانسخه.
3. في GitHub: إعدادات المستودع ← **Secrets and variables** ← **Actions** ← أضف سراً باسم `EXPO_TOKEN` والصق الرمز.

بعد النشر:
- سجّل الدخول في تطبيق **Expo Go** بنفس حساب Expo، وسيظهر المشروع في قائمة المشاريع.
- أو افتح صفحة آخر تشغيل في تبويب **Actions** على GitHub، وستجد رابط `exp://` ورمز QR.

## نسخة الويب (رفعها على استضافة عادية)

الملفات الجاهزة للرفع موجودة في مجلد `web-dist/`، ونفسها مضغوطة في الملف `qr-code-app-web.zip`.

1. نزّل الملف `qr-code-app-web.zip`.
2. ادخل على لوحة تحكم الاستضافة وافتح **مدير الملفات** (File Manager).
3. افتح المجلد الذي تريد أن يظهر فيه الموقع، مثلاً `public_html` أو مجلداً داخله مثل `public_html/barcode`.
4. ارفع الملف المضغوط، ثم اختر **استخراج** (Extract) في نفس المكان.
5. تأكد أن `index.html` صار مباشرة داخل المجلد (وليس داخل مجلد فرعي)، ثم احذف الملف المضغوط.
6. افتح عنوان الموقع في المتصفح.

الموقع ملفات ثابتة فقط (بدون قاعدة بيانات أو PHP)، ويعمل من جذر النطاق أو من أي مجلد فرعي.
في نسخة الويب يُنزَّل الباركود كصورة PNG عند الضغط على "حفظ الصورة".

لإعادة بناء نسخة الويب بعد أي تعديل: `npm run build:web`.

## رفع المنيو إلى Cloudinary

- الرفع يتم من التطبيق مباشرة عبر إعداد رفع غير موقّع (`qr_menu_unsigned`)، لذلك **لا يوجد أي مفتاح سري داخل التطبيق**.
- هذا الإعداد يُنشأ تلقائياً من GitHub بالملف `.github/workflows/qr-code-app-cloudinary-setup.yml`
  باستخدام السر `CLOUDINARY_API_SECRET`، ثم يجرّب رفع صورة وملف PDF ويتأكد أنهما يفتحان.
- الملفات تُحفظ في مجلد `qr-menus` في حسابك، والصيغ المسموحة: صور (jpg, png, webp, heic) و PDF، بحد أقصى ١٠ ميجابايت.
- لتعديل اسم الحساب أو الإعداد: `src/cloudinary.js`.

## مكونات المشروع

```
qr-code-app/
├── App.js                  نقطة البداية والتنقل بين الشاشات
├── app.json                إعدادات التطبيق (الاسم، الأذونات بالعربي)
├── eas.json                إعدادات خدمة EAS
├── public/index.html       قالب صفحة الويب
├── scripts/build-web.js    بناء نسخة الويب وضغطها
├── web-dist/               نسخة الويب الجاهزة للرفع
└── src/
    ├── theme.js            الألوان والخطوط وأدوات اتجاه اليمين لليسار
    ├── qrTypes.js          أنواع الباركود: الحقول والتحقق وصيغة المحتوى
    ├── cloudinary.js       رفع ملف المنيو إلى Cloudinary
    ├── qrImage.js          حفظ ومشاركة صورة الباركود على الجوال
    ├── qrImage.web.js      تنزيل ومشاركة صورة الباركود في الويب
    ├── components/
    │   ├── ui.js           الشريط العلوي والأزرار والنصوص
    │   ├── Fields.js       حقول الإدخال (نص، اختيار، تاريخ ووقت، رفع ملف)
    │   ├── UploadField.js  اختيار صورة/PDF المنيو ورفعه
    │   └── DateTimeInput*.js اختيار التاريخ والوقت (جوال / ويب)
    └── screens/
        ├── HomeScreen.js   الشاشة الرئيسية وقائمة الأنواع
        ├── FormScreen.js   نموذج الإدخال لكل نوع
        └── ResultScreen.js عرض الباركود والحفظ والمشاركة واللون والشعار
```

## المكتبات المستخدمة

كلها مجانية ومدعومة داخل Expo Go (ميزة المنيو فقط تستخدم حساب Cloudinary):

| المكتبة | الاستخدام |
| --- | --- |
| `react-native-qrcode-svg` + `react-native-svg` | رسم الباركود محلياً |
| `qrcode` | رسم صورة الباركود بدقة عالية في نسخة الويب |
| `react-native-web` + `react-dom` | نسخة الويب |
| `react-native-view-shot` | تحويل الباركود إلى صورة PNG |
| `expo-media-library` | الحفظ في معرض الصور |
| `expo-sharing` | المشاركة |
| `expo-image-picker` | اختيار الشعار وصورة المنيو |
| `expo-document-picker` | اختيار ملف PDF للمنيو |
| `@react-native-community/datetimepicker` | اختيار تاريخ ووقت الحدث |

## ملاحظات

- في Expo Go على أندرويد قد يطلب الحفظ في المعرض إذناً إضافياً؛ إن تعذّر الحفظ يمكن استخدام زر **مشاركة** ثم اختيار حفظ الصورة.
- رقم واتساب يُكتب مع رمز الدولة، والأرقام السعودية المحلية (05xxxxxxxx) تُحوَّل تلقائياً إلى الصيغة الدولية.
- الموقع الجغرافي يُحفظ كرابط خرائط جوجل ليفتح على الآيفون والأندرويد معاً.
